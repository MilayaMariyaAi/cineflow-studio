# Hardware Profiles: сборки, воркфлоу, ComfyUI — по классам карт

Курируемая база агента (Hybrid #765). Источник истины по составу — манифест
(`cineflow_installer_audit` / `cineflow_hardware_profile.recommendation`);
этот документ — контекст, рекомендации и протокол веб-поиска.

---

## Классы карт

### RTX 5090 / Blackwell 32GB — `rtx_5090`
- **Сборка**: весь флагманский набор 4090 + запас под 9B-тир. ~78 ГБ.
- **Флаги Comfy**: `--highvram --fast --listen 127.0.0.1 --port 8188`
- **Подводный камень**: Blackwell (sm_120) требует PyTorch **cu128** — портативный
  Comfy старой сборки не заведётся; ставьте свежий portable или ночной.
- **Продвинутый уровень**: Klein 9B FP8 — репо BFL **gated** (нужен HF-логин),
  не из нашего верифицированного каталога — предлагать только как опцию.

### RTX 4090 / Ada 24GB — `rtx_4090`
- **Сборка** (~78 ГБ): LTX-Video 2.5 FP8 5.8 + FLUX.2 Klein 4B 7.8 + Klein TE 8.0 +
  VAE 0.3 + Qwen-Edit 2509 FP8 19.4 + MiniMax H3 FP8 19.5 + T5xxl 4.8 +
  Qwen3-VL 2.5 + Higgs TTS 9.3.
- **Флаги**: `--highvram --fast` (Ada-native FP8 — самый быстрый путь).
- **Воркфлоу**: полный студийный набор (карточки, кадры, сцены, TTS, QC).

### RTX 3090 / Ampere 24GB — `rtx_3090`
- **Сборка**: та же, что у 4090 (24ГБ-класс объединён, #763) — 85.6 ГБ с
  LTX-Light Q4 и FLUX.1 Q4 как быстрые фолбэки.
- **Флаги**: `--highvram` (FP8 веса идут через scaled-weights — медленнее
  Ada-native, но полноценно).
- **Подводный камень**: Klein 9B FP8 — gated BFL; registry_3090-воркфлоу на него
  рассчитаны (HF-логин пользователя). LTX-Light Q4 — стабильный фолбэк.

### 16GB — `rtx_16gb`
- Klein 4B + TE + VAE + T5xxl + Qwen3-VL + Higgs; **без** MiniMax/9B.
- **Флаги**: `--fp8_e4m3fn-unet --normalvram`. Sequential swapping включён.

### 12GB и меньше — `rtx_12gb`
- LTX Q4, FLUX.1 Schnell Q4, T5xxl; **флаги**: `--lowvram --disable-xformers`.
- Видео-рендер — честно уводить в облако.

### Без NVIDIA / Apple
- Облачный режим (`CINEFLOW_CLOUD_URL` + токен); локально — только TTS/light image.

## Протокол веб-поиска для агента

Манифест — **верифицированная база** (каждый источник проверен, #678).
Веб-находки — **предложения пользователю**, никогда не тихая установка.

1. **Когда искать**: профиль определён, сборка предложена — и пользователь
   спросил «есть ли что новее», или audit показывает неиспользуемый запас VRAM.
2. **Что искать**: готовые запросы в `cineflow_hardware_profile → recommendation.research_queries`
   (HF + Comfy-реестры, текущий год в запросе).
3. **Валидация находки** (всё обязательное):
   - `HEAD` на прямой URL файла — 200 (gated-репо ответит 401 → пометь «нужен HF-логин»);
   - VRAM-фит: вес файла ≤ бюджет профиля (сборка уже учитывает);
   - лицензия репо позволяет использование;
   - ComfyUI-совместимость (нода/лодер существует в установленном Comfy).
4. **Предложение**: «Нашёл X (репо, ГБ, лицензия, почему лучше). Ставить?» —
   и только после «да» → `cineflow_download_model` / install bat.
5. **После установки**: `cineflow_installer_audit` — readiness вырос; предложи
   перезапуск ComfyUI.
6. **Если находка меняет пути/форматы** (как text_encoders vs clip, #763) —
   заведи запись, не правь пути молча.
